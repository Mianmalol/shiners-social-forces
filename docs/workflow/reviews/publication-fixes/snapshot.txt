# Golden shiners: social-force dataset

Public mirror of Jacob Davidson's Mosaic-format golden-shiner dataset, shared November 5, 2026, for social-force modeling. Ten trials contain tracks with midline pose, directed visual networks, and videos for groups of 10, 30, 70, and 151 fish.

**Analysis results:** read the [session account](docs/session-summary.md) for our

All three source archives are hosted in this repository's release. The tracks and networks ZIPs are split into ordered binary parts because GitHub limits each release asset to under 2 GiB. Reassembly restores the original ZIPs byte for byte; no data has been transformed or omitted.

## Download and restore

With [GitHub CLI](https://cli.github.com/), download the release assets into a new directory:

```sh
gh release download data-2026-11-05 --repo Mianmalol/shiners-social-forces --dir downloads
```

Clone this small repository or download [`scripts/restore_archives.py`](scripts/restore_archives.py), then run:

```sh
python3 scripts/restore_archives.py --directory downloads
cd downloads
shasum -a 256 -c SHA256SUMS
```

The Python script needs only the standard library. It verifies the downloaded parts, reconstructs the split archives, and verifies the original archive checksums. It keeps the parts until you choose to remove them. On Linux, `sha256sum -c SHA256SUMS` is equivalent to the command above.

Extract **all three archives into the same destination** so their tracks, features, and media directories form one Mosaic dataset:

```sh
unzip shiners-tracks.zip
unzip shiners-networks.zip
unzip shiners-videos.zip
```

Allow extra disk space for both the downloaded parts, reconstructed ZIPs, and extracted data. The full archive inventory and hashes are in the release's `release-manifest.json`.

## Understand the data

Read the **[original dataset README](docs/source-README.md)** for the schema, trial list, coordinate conventions, segment gaps, identity reconstruction, video alignment, and worked loading examples. The original is preserved byte for byte and is also included as release asset `README.md`.

- Tracks: one row per fish per frame, including image-coordinate position, measured heading, body length, a 21-point midline, and two eye positions.
- Visual networks: one row per directed visible pair per frame, with observer `id1`, observed fish `id2`, ray count, angular size, and pixel distance.
- Videos: joined recordings for the nine smaller-group trials and the original single recording for the 151-fish trial.
- Mosaic manifest: `dataset.yaml` is included in the source archives. [Mosaic](https://github.com/ecodylicscience/mosaic) is the upstream analysis platform; pandas and pyarrow suffice to read the Parquet tables.

For derivatives, keep recording segments separate and never difference across segment joins. Coordinates are pixels with y increasing downward; see the source README for the 151-fish body-length caveat. The source documents a **visual interaction network**, not a learned visual identity embedding. Midpoint curvature must be defined and derived from the midline if needed; it is not listed as a ready-made track column in the README.

# Session account: from dataset audit to ten-trial comparison

November 7, 2026. This publication packages the descriptive analysis, its evidence,
and a reproducible workflow. It does not fit a social-force model or establish
leadership, influence, or causation. Start with the [comparison report](../reports/comparison/README.md)
for the plots and the [workflow status](workflow/status.md) for review evidence.

## What we did

We first separated three scientific tasks: **describe behavior → map candidate
responses → test what information predicts those responses**. We completed the
requested descriptive measurements in five chapters: individual motion, body
posture, school organization, spatial relationships, and reconstructed visual
access. Broader extensions in the original plan, including local alignment and
interaction persistence, remain future work.

We audited one 10-fish recording, defined the measurements, checked them on small
synthetic examples, and produced a five-chapter pilot with selected video overlays.
We then processed all ten track tables and all supplied visual-network rows under
the same analysis code and configuration: **10,827,539 fish-frame observations,
266,688,111 directed network rows, and 239,246 observed group frames**. There are
three recordings each at 10, 30 and 70 fish, and one at 151 fish. These row counts
are measurement volume, not independent experimental replication. No additional
video inspection was performed for the ten-trial extension.

An initial comparison run stopped when it encountered nonpositive body lengths.
We found 22 such observations across 14 trial-frames, defined explicit handling,
then regenerated every retained trial. Positive lengths define the reference scale;
curvature is undefined on collapsed poses. We retained finite positions and headings
as recorded measurements and separately removed affected frames, recomputing motion
without crossing the new gaps. The largest resulting median changes were 0.000110
for alignment and 0.0000731 for circulation. This checks those anomalies, not all
possible tracking errors. The stopped run remains an ignored local cache.

## How we treated the data

- **Continuity and scale:** derivatives never cross recording joins or gaps. Motion
  uses an 11-frame cubic smoothing filter, with 7- and 15-frame sensitivities and
  boundary exclusions. Distances and speeds use each trial's median positive body
  length, not centimeters. Flagged heading jumps are masked, not automatically repaired.
- **Definitions:** alignment P measures agreement of raw body headings on a 0–1
  scale. The school center is the mean fish position. Circulation C measures
  agreement of tangential movement around that moving center, after subtracting
  the school's mean velocity. It is neither angular speed nor a validated milling
  classifier. Posture comes from the recorded midline; visual links describe
  ray-cast geometric access, not attention or influence.
- **Comparisons:** each trial supplies an estimate. Plotted 5th–95th percentiles
  describe within-trial variation, not confidence intervals. We tested heading
  exclusions, duration matching, smoothing, circulation cutoffs, affected-frame
  removal, and an explicitly illustrative length-scale scenario for the 151-fish
  recording. All ten trials have now been explored; none is an untouched confirmatory set.

## What we learned

The single 151-fish recording has median P=0.641 and C=0.484, both within the

## Why only 6–11% of frames qualify for circulation

The chosen reporting rule first requires finite positions and velocities for all
fish. At least 80% must then move at least 0.5 reference body lengths/s relative
to the school and lie more than 10⁻⁶ body lengths from its center, so their radial
direction is defined. For 70 fish, that means at least **56 qualifying fish in
the same frame**. Both trials have a median of only 41 qualifying fish.

| --- | ---: | ---: | ---: |
| 70-fish/0107 | 24,578 | 84 | 2,598 (10.57%) |

P uses raw headings: changing the smoothing window changes P only through the heading-jump exclusion mask, so the window sweep is not an independent test of smoothing the alignment signal. This describes these recordings; it does not show that adding fish causes weaker social alignment. The 70-fish trials also have the lowest median speeds, so activity and global alignment co-vary here; speed-stratified alignment has not yet been analyzed. No experimental control or dependent-fish null was fitted.

Median C ranges are **0.287–0.383, 0.268–0.397, and 0.379–0.781** at N=10, 30, 70. Adjacent ranges overlap, so C does not meet the strict monotone criterion. The two high-C 70-fish trials, 0107 and 0124, have only 10.6% and 5.9% primary coverage. Calling them continuously circling schools, or treating those percentages as milling time, would exceed the evidence.

## 2. Why the circulation cutoff matters

![How many fish qualify in the two low-coverage trials](figures/05-circulation-eligibility.png)

This diagnostic counts qualifying fish in each velocity-defined frame. The rule
requires at least 56 of 70 fish; both trials have a median of only 41. Trial 0107
has 2,598 eligible frames out of 24,578 (10.57%); trial 0124 has 1,438 out of 24,533
(5.86%). Only 84 frames in each trial have undefined velocities. Those frames are
outside the histogram but remain in the coverage denominator. The other exclusions
come from the relative-speed/radial-direction rule, not absent track rows. Lowering
only the relative-speed cutoff to 0.25 BL/s raises coverage to 74.6% and 79.1%.
School-relative speed can be small even when fish swim rapidly together. These
percentages measure eligibility under our chosen rule, not time spent circling.

![Circulation eligibility and threshold sensitivities](figures/02-circulation-thresholds.png)

The upper-left panel shows how much data remains; upper-right shows each cutoff's median on its own selected frames. Lower-left holds frames fixed at those qualifying at all three cutoffs, which is exactly the 1.0-eligible, high-relative-motion subset. Fish contributing within those frames can still differ. Lower-right keeps the 0.5-cutoff C calculation fixed and changes its overlapping frame set. Its flat segment from 0.25 to 0.5 is identical by construction, not evidence of robustness. Missing C markers mean undefined summaries, never zero. Eligibility also depends on group size and how fish speeds co-vary under the requirement that at least 80% of fish qualify; coverage is not a group-size-neutral estimate of time spent circling.

Trial 70-fish/0107 illustrates the main selection issue. At 0.25 BL/s, C is measurable in 74.6% of frames and its median is 0.441. At 0.5, coverage falls to 10.6% and the median becomes 0.781. At 1.0 there are no eligible frames; the prespecified three-way intersection is therefore empty. Trial 0124 also has no 1.0-eligible frames.

An explicitly exploratory [pairwise comparison](tables/threshold-pairs.csv) uses the 2,598 frames shared by 0.25 and 0.5 in 0107. On those same frames, the lower-cutoff median is already 0.742, compared with 0.781 at the higher cutoff. Most of the difference from 0.441 to 0.781 therefore reflects selection of different moments; a smaller part reflects which fish contribute within those moments. These are descriptive differences between medians, not causal effects or independent-frame tests. All 30 threshold pairs, including undefined comparisons, are retained with [provenance](tables/threshold-pairs-manifest.json).

The focal fish's contribution to school-average velocity was also checked. Subtracting the other-fish mean rescales relative velocity by N/(N−1), leaving directions unchanged. Applying the equivalent threshold increases C coverage by 0.29–10.45 percentage points across these trials; the largest absolute change in median C is 0.0246. It does not rescue a monotone group-size ordering. This is a cutoff sensitivity, not a correction to the valid moving-centroid description.

#!/usr/bin/env python3
"""Explain circulation coverage from frozen per-frame comparison outputs.

Run after the comparison pipeline has created collective.csv for both trials.
Only this script's derived table, manifest, and figure are written.
"""
import argparse
import hashlib
import json
from pathlib import Path
import platform

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd


TRIALS = ("70-fish__0107", "70-fish__0124")
REPO = Path(__file__).resolve().parents[1]
COUNT_ATOL = 1e-8


def digest(path):
    return hashlib.sha256(Path(path).read_bytes()).hexdigest()


def eligibility_summary(stem, summary, config, collective):
    """Recover integer fish counts and cross-check the actual reporting mask."""
    fish = summary["fish"]
    if isinstance(fish, bool) or not isinstance(fish, int) or fish < 2:
        raise ValueError(f"{stem}: fish must be an integer >= 2")
    fraction = float(config["circulation_min_fraction"])
    speed = float(config["low_speed_bl_s"])
    if not np.isfinite(fraction) or not 0 < fraction <= 1:
        raise ValueError(f"{stem}: invalid minimum fraction")
    if not np.isfinite(speed) or speed <= 0:
        raise ValueError(f"{stem}: invalid speed cutoff")
    # Use the same >= fraction comparison as the original metric. This avoids
    # a floating-point ceil error at exact integer-count boundaries.
    required = int(np.flatnonzero(np.arange(fish + 1) / fish >= fraction)[0])
    required_columns = {"frame", "eligible_fraction", "circulation"}
    if not required_columns.issubset(collective.columns):
        raise ValueError(f"{stem}: missing required columns")
    frames = collective["frame"].to_numpy(dtype=float)
    if (not len(frames) or not np.isfinite(frames).all()
            or not np.equal(frames, np.rint(frames)).all()
            or not (np.diff(frames) > 0).all()):
        raise ValueError(f"{stem}: frames must be unique increasing integers")
    if len(frames) != summary["quality"]["frames"]:
        raise ValueError(f"{stem}: tracked-frame denominator mismatch")
    fractions = collective["eligible_fraction"].to_numpy(dtype=float)
    circulation = collective["circulation"].to_numpy(dtype=float)
    if np.isinf(fractions).any() or np.isinf(circulation).any():
        raise ValueError(f"{stem}: infinities are not missing values")
    defined = np.isfinite(fractions)
    if ((fractions[defined] < 0) | (fractions[defined] > 1)).any():
        raise ValueError(f"{stem}: eligible fractions outside [0, 1]")
    scaled_counts = fractions[defined] * fish
    counts = np.rint(scaled_counts).astype(int)
    if not np.allclose(scaled_counts, counts, rtol=0, atol=COUNT_ATOL):
        raise ValueError(f"{stem}: eligible fractions do not encode integer fish counts")
    if "eligible_fish_count" in collective:
        saved = collective["eligible_fish_count"].to_numpy(dtype=float)
        if (np.isinf(saved).any() or not np.array_equal(np.isfinite(saved), defined)
                or not np.allclose(saved[defined], counts, rtol=0, atol=COUNT_ATOL)):
            raise ValueError(f"{stem}: saved eligible fish count mismatch")
    accepted_mask = np.zeros(len(frames), dtype=bool)
    accepted_mask[defined] = counts >= required
    finite_c = np.isfinite(circulation)
    if not np.array_equal(accepted_mask, finite_c):
        raise ValueError(f"{stem}: qualifying frame mask differs from finite circulation")
    if ((circulation[finite_c] < -1e-12) | (circulation[finite_c] > 1 + 1e-12)).any():
        raise ValueError(f"{stem}: circulation outside [0, 1]")
    accepted = int(accepted_mask.sum())
    coverage = accepted / len(frames)
    if accepted != summary["circulation"]["n"]:
        raise ValueError(f"{stem}: circulation summary count mismatch")
    if not np.isclose(coverage, summary["circulation_eligible_frame_fraction"], rtol=0, atol=1e-12):
        raise ValueError(f"{stem}: circulation summary coverage mismatch")
    # The saved eligibility mask cannot separate radius failures from relative
    # speed failures. It can verify that undefined frames have undefined velocity.
    velocity_undefined = None
    if "centroid_speed_bl_s" in collective:
        centroid_speed = collective["centroid_speed_bl_s"].to_numpy(dtype=float)
        if np.isinf(centroid_speed).any():
            raise ValueError(f"{stem}: infinite centroid speed")
        velocity_undefined = int((~np.isfinite(centroid_speed)).sum())
        if not np.array_equal(~np.isfinite(centroid_speed), ~defined):
            raise ValueError(f"{stem}: undefined eligibility and velocity masks differ")
    return {
        "trial": stem,
        "fish": fish,
        "low_speed_bl_s": speed,
        "circulation_min_fraction": fraction,
        "required_qualifying_fish": required,
        "tracked_frames": len(frames),
        "eligibility_defined_frames": int(defined.sum()),
        "eligibility_undefined_frames": int((~defined).sum()),
        "velocity_undefined_frames": velocity_undefined,
        "accepted_frames": accepted,
        "defined_but_below_requirement_frames": int(defined.sum()) - accepted,
        "coverage_all_tracked_frames": coverage,
        "median_qualifying_fish": float(np.median(counts)) if len(counts) else None,
        "qualifying_fish_p05_p95": np.quantile(counts, [.05, .95]).tolist() if len(counts) else None,
        "histogram_fish_count": list(range(fish + 1)),
        "histogram_frame_count": np.bincount(counts, minlength=fish + 1).tolist(),
    }


def load_trial(root, stem):
    folder = root / "trials" / stem
    paths = {name: folder / name for name in ("summary.json", "config.json", "collective.csv", "provenance.json")}
    provenance = json.loads(paths["provenance.json"].read_text())
    for name in ("summary.json", "config.json", "collective.csv"):
        if digest(paths[name]) != provenance["output_hashes"].get(name):
            raise ValueError(f"{stem}: saved provenance hash mismatch for {name}")
    metric = "src/shiners/metrics.py"
    if digest(REPO / metric) != provenance["source_hashes"].get(metric):
        raise ValueError(f"{stem}: metric source differs from the frozen run")
    result = eligibility_summary(
        stem, json.loads(paths["summary.json"].read_text()),
        json.loads(paths["config.json"].read_text()), pd.read_csv(paths["collective.csv"]),
    )
    hashes = {str(path.relative_to(root)): digest(path) for path in paths.values()}
    return result, hashes

"""Run configured trials sequentially in fresh processes; never overwrite results."""
from __future__ import annotations

import argparse
import hashlib
import json
from pathlib import Path
import re
import subprocess
import sys
import time


ROOT = Path(__file__).resolve().parents[1]
INPUT_MEMBERS = ('tracks.parquet', 'networks.parquet')


def file_hash(path):
    digest = hashlib.sha256()
    with Path(path).open('rb') as stream:
        for block in iter(lambda: stream.read(1024*1024), b''):
            digest.update(block)
    return digest.hexdigest()


def read_json(path):
    try:
        value = json.loads(Path(path).read_text())
        if not isinstance(value, dict):
            raise ValueError('Expected a JSON object')
        return value
    except (OSError, ValueError) as exc:
        raise ValueError(f'Cannot read valid JSON: {path}') from exc


def downloads_ready(data):
    """The fetcher atomically saves each member before adding its provenance."""
    provenance = data/'provenance.json'
    if not provenance.is_file():
        return False
    files = read_json(provenance).get('files', {})
    if not isinstance(files, dict):
        raise ValueError(f'Invalid fetch member manifest: {provenance}')
    for name in INPUT_MEMBERS:
        path = data/name
        entry = files.get(name, {})
        if not isinstance(entry, dict):
            raise ValueError(f'Invalid fetch member entry: {name}')
        sha = entry.get('sha256')
        if not path.is_file() or not isinstance(sha, str) or not re.fullmatch(r'[0-9a-fA-F]{64}', sha):
            return False
        if entry.get('size') != path.stat().st_size:
            return False
    return True


def _resolve_recorded(path, root):
    path = Path(path)
    return path.resolve() if path.is_absolute() else (root/path).resolve()


def validate_completed(output, data, config, repo=ROOT):
    """Accept only complete results with all recorded digests still matching."""
    if not (output/'summary.json').is_file() or not (output/'provenance.json').is_file():
        raise ValueError(f'Partial output; leave untouched and choose a new output root: {output}')
    provenance = read_json(output/'provenance.json')
    manifests = {}
    for category, root in [('input_hashes', repo), ('source_hashes', repo), ('output_hashes', output)]:
        hashes = provenance.get(category)
        if not isinstance(hashes, dict) or not hashes:
            raise ValueError(f'Missing {category} in {output}/provenance.json')
        manifests[category] = {}
        for name, expected in hashes.items():
            path = _resolve_recorded(name, root)
            if category == 'output_hashes' and not path.is_relative_to(output.resolve()):
                raise ValueError(f'Output hash path escapes trial directory: {name}')
            if not path.is_file() or file_hash(path) != expected:
                raise ValueError(f'Resume refused: {category} mismatch: {path}')
            manifests[category][path] = expected
    required_inputs = {(data/name).resolve() for name in (*INPUT_MEMBERS, 'provenance.json')}
    if set(manifests['input_hashes']) != required_inputs:
        raise ValueError(f'Resume refused: input manifest does not match selected trial: {data}')
    required_sources = {config.resolve(), (repo/'src/shiners/compare_trial.py').resolve(),
                        (repo/'src/shiners/metrics.py').resolve(), (repo/'src/shiners/network_summary.py').resolve()}
    if not required_sources.issubset(manifests['source_hashes']):
        raise ValueError('Resume refused: config or analysis source missing from provenance')
    recorded_outputs = set(manifests['output_hashes'])
    actual_outputs = {p.resolve() for p in output.rglob('*') if p.is_file() and p != output/'provenance.json'}
    if (output/'summary.json').resolve() not in recorded_outputs or recorded_outputs != actual_outputs:
        raise ValueError(f'Resume refused: incomplete or unrecorded output files: {output}')
    summary = read_json(output/'summary.json')
    network = summary.get('network')
    if (summary.get('trial') != data.name.replace('__', '/')
            or not isinstance(network, dict) or 'network_rows' not in network):
        raise ValueError(f'Resume refused: wrong trial or incomplete network analysis: {output}')
    if not provenance.get('fetch_member_hashes_match'):
        raise ValueError('Resume refused: fetch member validation is absent')


def run(config, data_root, output_root, trials=None, resume=False, wait_for_downloads=False,
        poll_interval=10):
    config, data_root, output_root = [Path(p).resolve() for p in (config, data_root, output_root)]
    configured = read_json(config).get('trials')
    if (not isinstance(configured, list) or not configured
            or any(not isinstance(t, str) or not re.fullmatch(r'\d+-fish__[A-Za-z0-9_-]+', t) for t in configured)
            or len(configured) != len(set(configured))):
        raise ValueError('Config trials must be a nonempty list of unique safe trial names')
    selected = list(dict.fromkeys(trials)) if trials else configured
    if any(t not in configured for t in selected):
        raise ValueError('Every --trial must occur in config trials')
    for trial in selected:
        data, output = data_root/trial, output_root/trial
        if output.exists() and (not output.is_dir() or any(output.iterdir())):
            if not resume or not output.is_dir():
                raise ValueError(f'Nonempty output; use --resume only for verified completed results: {output}')
            validate_completed(output, data, config)
            print(f'{trial}: verified complete; skipping', flush=True)
            continue
        announced = False
        while not downloads_ready(data):
            if not wait_for_downloads:
                raise ValueError(f'Input members/provenance are incomplete: {data}; use --wait-for-downloads to wait')
            if not announced:
                print(f'{trial}: waiting for tracks and networks with completed fetch provenance', flush=True)
                announced = True
            time.sleep(poll_interval)
        print(f'{trial}: starting fresh analysis process', flush=True)
        subprocess.run([sys.executable, '-m', 'shiners.compare_trial', '--data', str(data),
                        '--output', str(output), '--config', str(config)], cwd=ROOT, check=True)


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--config', type=Path, default=ROOT/'configs/comparison.json')
    parser.add_argument('--data-root', type=Path, default=ROOT/'data/trials')
    parser.add_argument('--output-root', type=Path, default=ROOT/'reports/comparison/trials')
    parser.add_argument('--trial', action='append', help='Configured trial name; repeat to select several')
    parser.add_argument('--resume', action='store_true', help='Skip completed trials only after checking all saved hashes')
    parser.add_argument('--wait-for-downloads', action='store_true', help='Wait for both input members and fetch provenance')
    args = parser.parse_args(argv)
    try:
        run(args.config, args.data_root, args.output_root, args.trial, args.resume, args.wait_for_downloads)
    except (ValueError, subprocess.CalledProcessError) as exc:
        parser.exit(1, f'{exc}\n')


if __name__ == '__main__':
    main()
